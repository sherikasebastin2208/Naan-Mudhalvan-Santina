# Acceptance Criteria

- Parcel records can be created and use the expected auto-number format.
- Status can be set to Booked, In Transit, Out for Delivery or Delivered.
- Sender, receiver and delivery information are linked to the appropriate parcel records.
- `Parcel Details` Flow is active and returns the Prompt Builder response.
- Agentforce asks for Parcel ID when it is missing and returns parcel details for a valid ID.
- Permission set grants only the required object/field permissions to the intended user.
- Planned future-scope features are clearly distinguished from implemented features.
